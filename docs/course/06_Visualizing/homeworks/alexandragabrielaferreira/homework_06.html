Solution 2 - change order of condition

Switch the order of the conditions.

Let’s say I want to show control condition last and SEB first. We can use the filter function to create a new dataset with the rows in the order we want them -> wrong solution

treatment_condition = c("SEB", "PPD", "Ctrl")
reordered_data = data |> filter (Condition %in% treatment_condition)

str(reordered_data)

head(reordered_data, 10)

With the first code, I just filtered all the rows as long as they match any of the conditions. Not what I wanted.

Internet searching lead me to the arrange() function from dplyr package. Let’s test:

reordered_data_2 = data |> arrange(desc(Condition))
str(reordered_data_2)

column_conditions = reordered_data_2 |> pull(Condition)
column_conditions
unique(column_conditions)

Using the arrange function to sort by descending order Condition. Let’s plot!

Then I saw somewhere (maybe reddit?) that sort or arrange don’t have an impact on ggplot2.

Let’s see if turning Condition to a factor helps us use reorder later:

# turning conditions into a factor
reordered_data_2 = data
reordered_data_2$Condition = factor(reordered_data_2$Condition)
str(reordered_data_2[,1:5])

reordered_data_2 = reordered_data_2 |> arrange(desc(Condition))
str(reordered_data_2[,1:5])

reordered_data_2 = reordered_data_2 |> mutate(Condition=factor(Condition, levels=Condition))
str(reordered_data_2[,1:5])

The solution above also didn’t work!

Using the library forcats: 1. first turn “condition” into a factor using factor() 2. mutate the column condition based on a fct_reorder() from the forcats library to reorder it based on descending values for condition.

Explanation: as we factorialized Condition now Ctrl = 1, PPD = 2 and SEB = 3. When we reorder it based on descending values, SEB comes first, PPD remains in second and Ctrl is last. This structure is now passed to ggplot2.

# install.packages("forcats")
library(forcats)

reordered_data_2 = data
reordered_data_2$Condition = factor(reordered_data_2$Condition)
str(reordered_data_2[,1:5])

reordered_data_2 = reordered_data_2 |> mutate(Condition = fct_reorder(Condition, desc(Condition)))
str(reordered_data_2[,1:5])
# attribute colours to female and male:

shape_sex = c("Female" = 22, "Male" = 21)
fill_sex = c("Female" = darker_purples[1], "Male" = darker_purples[2])

#attribute colours to conditions:
stimulation_colours = list("Ctrl" = sakura_palette[1], "PPD" = sakura_palette[2], "SEB" = sakura_palette[3])

plot_2 = ggplot(reordered_data_2) + 
    aes(x=Condition, y=Tcell_frequency, colour=Condition) + #chose aesthetics, meaning the things to plot, any color by group should be included here so it's always kept.
    geom_boxplot(colour="black", linewidth=0.2) + 
    geom_beeswarm(size=2.5, cex=2.5, aes(shape=infant_sex, fill=infant_sex)) + #this provides the geometry we want, size for said geometry and how we want our datapoints in beeswarm to look like. always finish with + to add on layers
    scale_shape_manual(values=shape_sex) +
    scale_fill_manual(values=fill_sex) +
    coord_cartesian(ylim=c(0,100)) +
    scale_colour_manual(values=stimulation_colours) +
    theme_classic()
plot_2

So now we have a plot with reversed conditions.

One can also use this to reorder based on other values like median of value of T cell frequency for example.
